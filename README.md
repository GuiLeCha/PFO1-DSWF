# PFO1 - Landing de portafolio personal

Trabajo individual realizado para la materia Desarrollo de Software Frontend.

La idea del proyecto fue armar una landing personal usando HTML5 y CSS, con una presentación, mis habilidades, parte de mi recorrido y distintas formas de contacto.

## Sitio publicado

https://guillermo-chacon-pfo1.vercel.app/

## GitHub

Perfil: https://github.com/GuiLeCha

## Decisiones de diseño

Quise hacer una página simple y fácil de leer, usando principalmente blanco, negro y grises.

Para los textos usé Roboto y para los títulos Roboto Slab. Me gustó más esta combinación porque permite diferenciar los títulos sin cargar demasiado el diseño.

En el encabezado usé CSS Grid para acomodar el texto y la foto. También usé Grid en la sección de habilidades. Para el menú usé Flexbox, principalmente porque me permitía distribuir los enlaces y hacer que se acomodaran mejor cuando la pantalla se hacía más chica.

Para la versión responsive usé una media query. En pantallas chicas el encabezado pasa a una sola columna, la foto queda centrada y las habilidades también pasan de dos columnas a una.

También agregué algunos efectos con :hover y una transición en el botón del formulario.

## Uso de inteligencia artificial

Para este trabajo usé ChatGPT con plan Plus.

Uso ChatGPT habitualmente para estudiar, trabajar, buscar información y también como ayuda para desarrollar aplicaciones y proyectos personales o laborales.

En esta PFO lo fui usando como herramienta de consulta mientras avanzaba. Me sirvió para revisar código, entender algunas propiedades de CSS y probar distintas alternativas para el diseño.

También lo usé como ayuda en algunos requisitos puntuales que estaban pedidos en la consigna pero no desarrollados paso a paso en el material, por ejemplo, Google Fonts y la transición del botón.

Las sugerencias que fui consultando con IA las revisé y probé antes de usarlas. Algunas me sirvieron como estaban, otras las adapté y otras directamente las descarté.

El contenido personal y la decisión final sobre qué versión dejar fueron míos.
